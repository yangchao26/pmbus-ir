## 1. 总体定位

- **文档类型**: Omnion Power PMBus 应用手册 AN008
- **目标读者**: 系统工程师、固件工程师、FAE（含 PMBus 初学者）
- **产品范围**: 通用手册，覆盖所有 Omnion Power 数字电源产品，**不绑定特定型号**
- **编程示例语言**: Python
- **篇幅**: 不设上限，以写清楚、易读为准

## 2. 语言风格

- **正文语言**: 中文
- **专有名词**: 首次出现时 "中文（English）"，后续直接用英文
  - 例：包错误校验（Packet Error Check, PEC）→ 后文直接用 PEC
- **命令名称**: 始终用英文大写 + 命令码，如 `VOUT_COMMAND (0x21)`
- **寄存器名称**: 同上，如 `STATUS_WORD (0x79)`
- **信号名称**: 英文大写 + `#` 表示低电平有效，如 `SMBALERT#`
- **语气**: 专业、清晰、直接，避免口语化
