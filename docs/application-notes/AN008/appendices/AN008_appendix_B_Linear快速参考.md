# 附录 B Linear 格式编码/解码快速参考卡

> 本附录提供 PMBus Linear 数据格式（11-bit Linear 与 ULINEAR16）的编码/解码速查信息，方便工程师在开发中快速查阅。详细原理与背景参见第 5 章。

---

## B.1 核心公式

### 11-bit Linear（通用参数格式）

```text
Value = Y × 2^(N)
```

```text
15        11 10        0
+-----------+-----------+
| exponent  | mantissa  |
+-----------+-----------+
  5-bit TC    11-bit TC
```

| 字段 | 位数 | 类型 | 范围 |
|------|------|------|------|
| exponent（指数 N） | 5-bit | 二进制补码（Two's Complement） | -16 ~ +15 |
| mantissa（尾数 Y） | 11-bit | 二进制补码（Two's Complement） | -1024 ~ +1023 |

### ULINEAR16（电压专用格式）

```text
VOUT = Y × 2^(N)
```

| 字段 | 位数 | 类型 | 说明 |
|------|------|------|------|
| Y（尾数） | 16-bit | 无符号整数 | 0 ~ 65535 |
| N（指数） | — | 由 VOUT_MODE 命令指定 | 5-bit 二进制补码，-16 ~ +15 |

> **提示**: ULINEAR16 仅用于输出电压相关命令（VOUT_COMMAND、READ_VOUT 等），指数 N 存储在 `VOUT_MODE (0x20)` 中，不携带在数据字内。Omnion Power 模块默认 N = -12，分辨率 ≈ 0.244 mV。

## B.2 编码步骤（数值 → 2 字节）

以 11-bit Linear 为例，将物理值编码为 16-bit 数据字：

**Step 1 — 选择指数 N**
- 选择使尾数 Y 在 ±1023 范围内且精度最高的最小指数
- Omnion Power 模块多数命令固定 N = -3；VOUT 命令使用 VOUT_MODE 中的 N

**Step 2 — 计算尾数 Y**
```text
Y = Value / 2^(N)
```
- 若 Value = 0，则 Y = 0（指数任意）
- 若 |Y| > 1023，需增大 N 重新计算

**Step 3 — 将 N 和 Y 转换为二进制补码**
- N：5-bit 二进制补码
- Y：11-bit 二进制补码（负数需取反加 1）

**Step 4 — 组装 16-bit 数据字**
```text
数据字 = (N 的 5-bit 补码 << 11) | (Y 的 11-bit 补码 & 0x7FF)
高字节 = 数据字 >> 8
低字节 = 数据字 & 0xFF
```

---

## B.3 解码步骤（2 字节 → 数值）

**Step 1 — 重组 16-bit 数据字**
```text
数据字 = (高字节 << 8) | 低字节     # 总线低字节先传
```

**Step 2 — 提取 N 和 Y**
```text
N = data_word >> 11                  # 高 5-bit
if N >= 16: N -= 32                  # 转为有符号值

Y = data_word & 0x7FF                # 低 11-bit
if Y >= 1024: Y -= 2048              # 转为有符号值
```

**Step 3 — 计算物理值**
```text
Value = Y × 2^(N)
```

## B.6 Two's Complement 速查

### 5-bit 二进制补码（指数 N）

| 十进制 | 二进制 | 十进制 | 二进制 |
|--------|--------|--------|--------|
| +15 | 01111 | -1 | 11111 |
| +7 | 00111 | -3 | 11101 |
| +3 | 00011 | -5 | 11011 |
| +1 | 00001 | -7 | 11001 |
| 0 | 00000 | -8 | 11000 |
| — | — | -12 | 10100 |
| — | — | -16 | 10000 |

**快速转换方法**：
```text
正数 → 负数:  ~N + 1（取反加 1）
负数 → 正数:  ~N + 1（取反加 1）
判断符号:      bit 4 = 1 → 负数
```

### 11-bit 二进制补码（尾数 Y）

| 十进制 | 二进制 | 十进制 | 二进制 |
|--------|--------|--------|--------|
| +1023 | 01111111111 | -1 | 11111111111 |
| +256 | 00100000000 | -256 | 11100000000 |
| +1 | 00000000001 | -1024 | 10000000000 |
| 0 | 00000000000 | — | — |

**快速转换方法**：
```text
正数 → 负数:  ~Y + 1（取反加 1，保留 11-bit）
负数 → 正数:  ~Y + 1（取反加 1）
判断符号:      bit 10 = 1 → 负数
```

## B.7 快速计算示例

### 示例 1：电压编码 — 设置 3.3V 输出（ULINEAR16, VOUT_MODE N = -12）

```text
Step 1: N = -12（由 VOUT_MODE 指定）
Step 2: Y = 3.3 / 2^(-12) = 3.3 × 4096 = 13,516.8 → 13,517
Step 3: Y = 13,517 = 0x34AD（16-bit 无符号）
Step 4: 数据字 = 0x34AD
        高字节 = 0x34，低字节 = 0xAD

验证: 13,517 / 4096 = 3.300 V ✓
```

### 示例 2：电流编码 — 设置 10A 过流阈值（11-bit Linear, N = -3）

```text
Step 1: N = -3（Omnion 默认）
Step 2: Y = 10.0 / 2^(-3) = 10.0 × 8 = 80
Step 3: N = -3 → 补码 11101；Y = 80 → 二进制 00010100000
Step 4: 数据字 = [11101][00010100000]
        = 11101_00010_10000 = 0xE0A0
        高字节 = 0xE0，低字节 = 0xA0

验证: 80 × 0.125 = 10.0 A ✓
```

### 示例 3：温度编码 — 设置 105°C 过温阈值（11-bit Linear, N = -3）

```text
Step 1: N = -3
Step 2: Y = 105.0 / 0.125 = 840
Step 3: N = -3 → 11101；Y = 840 → 01101001000
Step 4: 数据字 = [11101][01101001000]
        = 11101_10110_01000 = 0xED48
        高字节 = 0xED，低字节 = 0x48

验证: 840 × 0.125 = 105.0 °C ✓
```

### 示例 4：功率编码 — 设置 500W 功率（11-bit Linear）

```text
Step 1: 尝试 N = -1 → Y = 500 × 2 = 1000（|Y| <= 1023 ✓）
Step 2: Y = 1000 → 01111101000
Step 3: N = -1 → 11111
Step 4: 数据字 = [11111][01111101000]
        = 11111_01111_10100 = 0xF7A4
        高字节 = 0xF7，低字节 = 0xA4

验证: 1000 × 0.5 = 500.0 W ✓
```

### 示例 5：负温度解码 — 数据字 0xEF60（11-bit Linear）

```text
Step 1: 数据字 = 0xEF60
Step 2: N = 0xEF60 >> 11 = 0x1D = 29 → 29 - 32 = -3
        Y = 0xEF60 & 0x7FF = 0x760 = 1872 → 1872 - 2048 = -176
Step 3: Value = -176 × 2^(-3) = -176 / 8 = -22.0 °C
```

## B.8 多重编码说明

同一个物理值可以有多种合法编码。例如 4.0 V：

| 指数 N | 尾数 Y | 数据字 | 验证 |
|--------|--------|--------|------|
| -3 | 32 | 0xE820 | 32 × 0.125 = 4.0 |
| -2 | 16 | 0xEE10 | 16 × 0.25 = 4.0 |
| -1 | 8 | 0xF708 | 8 × 0.5 = 4.0 |
| 0 | 4 | 0xFC04 | 4 × 1 = 4.0 |

> **工程意义**: 比较两个数据字是否代表相同物理值时，必须先解码再比较，不能直接比较原始数据字。写入命令时应使用设备约定的指数，参见具体产品 Datasheet。

## B.9 特殊值处理

| 条件 | 说明 |
|------|------|
| 尾数 Y = 0 | 无论 N 为何值，Value = 0（零的编码不唯一） |
| 数据字 = 0x0000 | N = 0, Y = 0，表示零值 |
| 数值溢出 | |Y| > 1023 时需增大 N 重新编码 |
| 负值 | 尾数 Y 使用 11-bit 补码负值表示 |
