# 第3章 硬件接口设计

> 本章介绍 Omnion Power 电源模块 PMBus 接口的硬件设计要点，包括引脚功能、接线拓扑、上拉电阻配置、PCB 布局建议和地址设定方法。通过本章学习，您将掌握从物理层到设备地址配置的完整硬件设计流程。

---

## 3.1 Omnion Power 模块 PMBus 引脚说明

Omnion Power 电源模块的 PMBus 接口通过专用引脚实现时钟、数据、地址选择和故障指示功能。这些信号引脚应采用低噪声控制信号布线，并以指定的信号地（SIG_GND）为参考。

### PMBus 信号引脚定义

| 引脚 | 信号名 | 方向 | 功能描述 |
|------|--------|------|----------|
| SCL | 串行时钟（Serial Clock） | 输入 | PMBus/SMBus 时钟信号，由主机产生，从设备同步采样 |
| SDA | 串行数据（Serial Data） | 双向 | PMBus/SMBus 双向数据传输线，开漏输出结构 |
| SMBALERT# | SMBus 报警（低电平有效） | 输出 | 故障指示输出，开漏结构。模块检测到报警条件时拉低通知主机 |
| CTRL/ON_OFF | 控制/开关使能 | 输入 | 硬件使能输入，与 PMBus `OPERATION` 命令配合控制模块启停 |
| ADDR | 地址选择（Address） | 输入 | PMBus 设备地址配置引脚，通过外接电阻设定从设备地址 |

> **注意**：信号名称中的 `#` 表示低电平有效（Active Low）。SMBALERT# 引脚在报警条件满足时被拉低，正常状态下保持高阻态。

### 引脚电气特性

PMBus 接口引脚采用开漏（Open-Drain）结构，需外部上拉电阻至逻辑高电平。关于开漏结构的工作原理和电气特性，详见第 2 章。

| 参数 | 符号 | 最小值 | 典型值 | 最大值 | 单位 |
|------|------|--------|--------|--------|------|
| 输入高电压 | VIH | 2.1 | — | 3.6 | V |
| 输入低电压 | VIL | — | — | 0.8 | V |
| 输出低电压 | VOL | — | — | 0.4 | V |
| 输出低电平吸收电流（CLK, DATA） | IOL | — | — | 4 | mA |
| 输出低电平吸收电流（SMBALERT#） | IOL | — | — | 2 | mA |
| 引脚电容 | CO | — | — | 0.7 | pF |

> **具体参数值**：参见具体产品 Datasheet

### 不使用 PMBus 时的引脚处理

若系统中不使用 PMBus 功能，建议按以下方式处理相关引脚：

| 引脚 | 处理方式 | 说明 |
|------|----------|------|
| SDA/SCL | 连接上拉电阻至 3.3V | 保持确定的空闲高电平状态，避免浮空引入噪声 |
| ADDR | 按默认地址要求连接电阻 | 若不连接电阻，模块使用默认地址 0x7F |
| SMBALERT# | 可悬空 | 开漏输出，无内部上拉，悬空时无影响 |
| CTRL/ON_OFF | 按模块启动要求连接 | 正逻辑：悬空或接高为 ON；负逻辑：短接 VIN(-) 为 ON |

### 3.2.1 基本接线拓扑

PMBus 采用主从架构，单条总线可连接一个主机（Master）和多个从设备（Slave）。基本接线拓扑如下：

> 图中应包含：主机、从设备（电源模块）、SCL/SDA 总线、上拉电阻、SIG_GND 连接

**基本接线要点**：

1. **总线结构**：SCL 和 SDA 为共享总线，所有设备并联连接
2. **参考地**：所有 PMBus 信号以 SIG_GND（信号地）为参考
3. **上拉电阻**：SCL 和 SDA 均需外接上拉电阻至 VDD（通常为 3.3V）
4. **终端处理**：总线两端无需终端电阻（不同于高速差分信号）

### 3.2.2 推荐的上拉电阻放置位置（主机端）

上拉电阻的放置位置直接影响信号完整性和总线可靠性。

**推荐方案：主机端集中上拉**

| 放置位置 | 优点 | 缺点 | 推荐度 |
|----------|------|------|--------|
| 主机端集中上拉 | 布线简洁，阻抗匹配好，易于调试 | 长距离布线时远端信号上升沿变缓 | ⭐⭐⭐ 推荐 |
| 各从设备分散上拉 | 改善远端信号质量 | 总并联电阻值计算复杂，可能过驱动 | ⭐⭐ 可选 |
| 主机+从设备双端上拉 | 信号质量最佳 | 电阻值需精确计算，设计复杂 | ⭐ 特殊场景 |

**上拉电阻推荐值**

| 总线速率 | 总线电容 | 推荐上拉电阻 | 适用场景 |
|----------|----------|--------------|----------|
| 100 kHz | < 100 pF | 4.7 kΩ ~ 10 kΩ | 短距离、少设备 |
| 100 kHz | 100~200 pF | 2.2 kΩ ~ 4.7 kΩ | 中等距离 |
| 400 kHz | < 100 pF | 2.2 kΩ ~ 4.7 kΩ | 标准模式 |
| 400 kHz | 100~200 pF | 1.0 kΩ ~ 2.2 kΩ | 需验证信号完整性 |

> **关于上拉电阻计算**：上拉电阻值的选择需综合考虑总线电容、目标速率和功耗。详细的计算方法和工程考量参见第 2 章。

### 3.2.3 PCB 布局建议

良好的 PCB 布局是确保 PMBus 可靠通信的基础。

**线宽与间距**

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 信号线宽 | ≥ 0.2 mm (8 mil) | 满足载流和制造要求 |
| 信号线间距 | ≥ 0.2 mm (8 mil) | 避免串扰 |
| SCL/SDA 间距 | ≥ 0.3 mm (12 mil) | 时钟与数据间增加隔离 |
| 与电源线间距 | ≥ 0.5 mm (20 mil) | 远离高 dv/dt 信号 |

**屏蔽与接地**

1. **信号地平面**：在 PMBus 信号层下方设置完整的 SIG_GND 参考平面
2. **屏蔽地线**：长距离走线时，SCL/SDA 两侧可布置地线保护（Guard Trace）
3. **过孔隔离**：信号换层时在换孔周围放置地过孔（Stitching Via）
4. **避免分割**：SIG_GND 平面避免分割，保持完整性

**线缆长度限制**

| 总线速率 | 最大线缆长度 | 备注 |
|----------|--------------|------|
| 100 kHz | ~ 1 米 | 标准模式，常规 PCB 走线 |
| 400 kHz | ~ 0.3 米 | 快速模式，需严格控制电容 |
| 100 kHz（外部线缆）| ~ 0.5 米 | 使用双绞线或屏蔽线 |

> **重要提示**：总线电容包括 PCB 走线电容、连接器电容、器件输入电容和线缆电容。总电容超过 200 pF 时，建议降低总线速率或使用总线缓冲器。

**布局检查清单**

- [ ] SCL/SDA 走线尽量短且等长
- [ ] 避免与高频开关信号平行走线
- [ ] 上拉电阻靠近主机端放置
- [ ] SIG_GND 与功率地单点连接
- [ ] 地址配置电阻靠近 ADDR 引脚

**设计要点**

|------|------|
| 地址分配 | 每个设备必须配置唯一地址（详见 3.3 节） |
| 总线电容 | 计算所有设备输入电容之和，确保总电容在允许范围内 |
| 上拉电阻 | 根据总电容重新计算上拉电阻值，可能需要减小阻值 |
| SMBALERT# | 多个设备的 SMBALERT# 可线与（Wire-AND）连接 |
| 星型 vs 菊花链 | 推荐星型拓扑，避免长菊花链导致的信号反射 |

**多设备总线电容计算**

```
总电容 C_total = C_pcb + C_connector + Σ(C_device) + C_cable

其中：
- C_pcb：PCB 走线电容（约 1~3 pF/cm）
- C_connector：连接器寄生电容（约 1~5 pF/引脚）
- C_device：器件输入电容（参见器件 Datasheet，通常 5~20 pF）
- C_cable：线缆电容（双绞线约 50~100 pF/m）
```

## 3.3 地址设定

### 3.3.1 硬件地址配置方式

Omnion Power 电源模块支持通过硬件引脚配置 PMBus 设备地址，适用于多设备系统中的地址冲突规避。

**7-bit 地址范围**

PMBus 使用 7-bit 地址格式，有效地址范围为 **0x08 ~ 0x77**（十进制 8 ~ 119）。

| 地址范围 | 状态 | 说明 |
|----------|------|------|
| 0x00 ~ 0x07 | 保留 | 通用呼叫地址、起始字节等 |
| 0x08 ~ 0x77 | 可用 | 用户可配置的从设备地址 |
| 0x78 ~ 0x7B | 保留 | 10-bit 地址扩展 |
| 0x7C ~ 0x7F | 保留 | 厂商特定、SMBus 设备默认 |

**地址配置方法**

Omnion Power 模块通过在 ADDR 引脚与 VOUT(-) 引脚之间连接电阻来配置地址。模块上电时采样 ADDR 引脚电压，根据电阻值确定设备地址。

| 电阻值 (kΩ) | 最近 E192 标准值 (kΩ) | PMBus 地址 |
|-------------|---------------------|-----------|
| 232 | 232 | 0x0A (10) |
| 210.5 | 210 | 0x0B (11) |
| 196 | 196 | 0x0C (12) |
| 186 | 187 | 0x0D (13) |
| 178.6 | 178 | 0x0E (14) |
| 172.4 | 172 | 0x0F (15) |
| 167.5 | 167 | 0x10 (16) |
| 163.2 | 162 | 0x11 (17) |
| 159.5 | 160 | 0x12 (18) |
| 156.3 | 156 | 0x13 (19) |
| 153.4 | 154 | 0x14 (20) |
| 150.8 | 152 | 0x15 (21) |
| 148.5 | 149 | 0x16 (22) |
| 146.3 | 146 | 0x17 (23) |

> **默认地址**：若 ADDR 引脚未连接电阻（悬空），模块使用默认地址 0x7F。

**配置注意事项**

1. **地址锁存**：地址在上电时采样并锁存，直到下次复位才会重新采样
2. **电阻精度**：建议使用 ±1% 精度的电阻，确保地址识别正确
3. **超范围处理**：若电阻值超出表中范围（< 10 kΩ 或 > 232 kΩ），模块将使用默认地址 0x7F
4. **电阻功率**：普通 1/16W 或 1/10W 贴片电阻即可满足要求

### 3.3.2 地址冲突避免

同一 PMBus 总线上的不同设备必须使用不同的地址，否则会导致通信冲突。

**地址冲突的后果**

| 现象 | 原因 | 排查方法 |
|------|------|----------|
| 总线忙/无响应 | 多个设备同时响应 | 检查各设备 ADDR 引脚电阻配置 |
| 数据错误 | 设备间数据冲突 | 使用逻辑分析仪捕获总线波形 |
| 间歇性故障 | 竞争导致时序紊乱 | 逐一断开设备排查 |

**冲突避免策略**

1. **硬件设计阶段**：在原理图中明确标注每个设备的地址
2. **生产测试**：增加地址扫描测试，确保无重复地址
3. **系统启动**：主机软件执行地址扫描，检测冲突并报警
4. **热插拔场景**：动态地址分配或预留地址空间

### 3.3.3 地址规划建议

合理的地址规划有助于系统维护和故障排查。

**推荐地址分配方案**

| 地址段 | 用途 | 示例 |
|--------|------|------|
| 0x10 ~ 0x1F | 主电源模块 | 0x10: 主路 1, 0x11: 主路 2 |
| 0x20 ~ 0x2F | 辅助电源模块 | 0x20: 辅助 1, 0x21: 辅助 2 |
| 0x30 ~ 0x3F | 预留/扩展 | 未来扩容使用 |
| 0x40 ~ 0x4F | 风扇控制器 | 若总线连接风扇控制器 |
| 0x50 ~ 0x5F | 温度传感器 | 若总线连接温度传感器 |

**地址规划检查清单**

- [ ] 所有设备地址唯一，无重复
- [ ] 避开系统保留地址（0x00~0x07, 0x78~0x7F）
- [ ] 与系统中其他 I²C/SMBus 设备地址不冲突
- [ ] 地址分配有逻辑规律，便于维护
- [ ] 文档中记录每个地址对应的设备位置

> **关于 SMBus ARP**：SMBus 规范定义了地址解析协议（Address Resolution Protocol, ARP）用于动态地址分配。Omnion Power 模块不支持 ARP，必须使用硬件引脚配置固定地址。
