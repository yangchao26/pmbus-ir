# 第 1 章 引言

> 本章说明 AN008 PMBus 应用手册的定位、目标读者与适用范围，定义全手册通用的术语与缩写，列出参考文档，并概述 Omnion Power 数字电源模块的 PMBus 通用特性。阅读本章后，读者将了解本手册的使用方式以及 Omnion Power 产品在 PMBus 协议层面的共性特征。

## 1.1 PMBus 应用手册的目的与适用范围

### 手册定位

Omnion Power PMBus 应用手册（AN008）是一份面向开发者的实用指南，覆盖 PMBus 接口从物理层到应用层的完整使用流程。本手册补充各产品 Datasheet 中 PMBus 部分的使用细节和编程指导，但不替代以下文档：

- **PMBus/SMBus/I²C 协议规范**——涉及协议细节时，本手册引导读者参考规范原文
- **产品 Datasheet**——具体电气参数、默认值、命令范围等以各产品 Datasheet 为准

本手册不是 PMBus/SMBus 规范的逐条翻译，而是以工程实践为导向，帮助读者快速掌握 Omnion Power 数字电源模块的 PMBus 接口使用方法。

### 目标读者

本手册面向以下三类读者：

| 读者角色 | 典型需求 |
|----------|----------|
| 系统工程师 | 理解 PMBus 总线架构、硬件接线、地址规划、系统集成 |
| 固件工程师 | 实现主机端 PMBus 驱动、命令交互、故障处理逻辑 |
| FAE | 辅助客户完成 PMBus 调试、解答协议与命令相关问题 |

本手册也适合 PMBus 初学者作为入门教程使用。第 2 章从 I²C 物理层讲起，逐步引入 SMBus 与 PMBus，不要求读者具备 PMBus 预备知识。

### 适用产品范围

本手册为**通用手册**，覆盖所有 Omnion Power 数字电源产品，包括但不限于：

- DC-DC 电源模块
- 中间母线变换器（IBC, Intermediate Bus Converter）
- 母线变换器（Bus Converter, Regulated）
- POL（Point-of-Load）模块
- AC-DC PSU 子模块

手册中描述的是各产品共有的 PMBus 特性行为。涉及具体型号的电气参数或差异时，以"参见具体产品 Datasheet"引导读者查阅对应文档。

### 与 Datasheet 的关系

| 内容类型 | AN008 | 产品 Datasheet |
|----------|-------|----------------|
| PMBus 协议原理与教程 | 详细讲解 | 不涉及 |
| 命令使用方法与编程指导 | 详细讲解 | 简要说明 |
| 电气规格（VIH、VOL 等） | 不涉及 | 详细列出 |
| 具体命令默认值与范围 | 通用描述，具体值引导查阅 Datasheet | 完整列出 |
| PCB 布局建议 | 提供通用指导 | 提供具体建议 |

> **提示**: 建议将 AN008 与对应产品的 Datasheet 配合使用。Datasheet 提供参数规格，AN008 提供使用方法。

### 编程示例语言

本手册的所有编程示例均使用 **Python** 语言，基于 `smbus2` 库实现。Python 示例便于快速验证和理解 PMBus 通信流程，主机端驱动开发的详细指导参见第 14 章。

## 1.2 术语与缩写

本节定义全手册通用的术语与缩写。后续章节首次出现这些术语时不再重复解释，直接使用缩写形式。

### 协议与标准相关

| 术语 / 缩写 | 全称 | 说明 |
|-------------|------|------|
| PMBus | Power Management Bus | 电源管理总线协议，由 System Management Interface Forum (SM-IF) 制定，在 SMBus 上定义电源管理命令集 |
| SMBus | System Management Bus | 系统管理总线，I²C 的受限超集，增加时序约束和电气要求 |
| I²C | Inter-Integrated Circuit | 内部集成电路总线，由 Philips (NXP) 制定，PMBus/SMBus 的物理层基础 |
| SM-IF | System Management Interface Forum | PMBus 规范的制定和维护组织 |

### 总线信号相关

| 术语 / 缩写 | 全称 | 说明 |
|-------------|------|------|
| SCL | Serial Clock Line | 串行时钟线，主机驱动，支持 Clock Stretching |
| SDA | Serial Data Line | 串行数据线，双向传输，开漏结构 |
| SMBALERT# | SMBus Alert | SMBus 告警信号，开漏输出，低电平有效，用于从设备向主机报告故障 |
| CTRL | Control | PMBus 控制信号（可选），用于设备使能控制 |
| WP | Write Protect | 写保护信号（可选），用于防止意外修改配置 |
| R/W# | Read/Write Bit | 地址字节中的读/写方向位，1 = 读，0 = 写 |

### 总线事务与协议机制

| 术语 / 缩写 | 全称 | 说明 |
|-------------|------|------|
| ACK | Acknowledge | 确认信号，接收方在每字节后拉低 SDA 表示确认 |
| NACK | Not Acknowledge | 非确认信号，接收方释放 SDA 表示未确认（传输结束或错误） |
| START (S) | Start Condition | 起始条件，SCL 为高时 SDA 产生下降沿 |
| STOP (P) | Stop Condition | 停止条件，SCL 为高时 SDA 产生上升沿 |
| Sr | Repeated Start | 重复起始条件，不释放总线的情况下重新发起传输 |
| ARA | Alert Response Address | 告警响应地址（0x0C），主机读取该地址以识别报警设备 |
| Clock Stretching | — | 时钟拉伸，从设备拉低 SCL 以延长处理时间 |
| Bus Timeout | — | 总线超时，SMBus 规定的超时机制（25 ms ~ 35 ms），用于检测总线挂死 |
| Bus Recovery | — | 总线恢复，主机发送额外 SCL 时钟脉冲以恢复被锁死的总线 |
| Arbitration | — | 总线仲裁，多主机同时访问时通过 SDA 线与逻辑决定优先级 |
| Open-Drain | — | 开漏输出，SDA/SMBALERT# 等信号的输出结构，需要外部上拉电阻 |

### 数据格式相关

| 术语 / 缩写 | 全称 | 说明 |
|-------------|------|------|
| Linear 格式 | Linear Format | PMBus 数值数据编码方式，使用 5-bit 指数 N + 11-bit 尾数 Y 表示：Value = Y × 2^N |
| Direct 格式 | Direct Format | PMBus 数值数据编码方式，使用参数 m、b、R 表示：Value = (Y × m + b) × 10^R |
| VOUT_MODE | — | 输出电压数据格式命令，定义 VOUT 相关命令使用的固定指数 |
| Two's Complement | 二进制补码 | 有符号整数的编码方式，用于 Linear 格式的指数和尾数 |
| LSB | Least Significant Byte/Bit | 最低有效字节/位；PMBus 多字节数据低字节先传（Little-Endian） |
| MSB | Most Significant Byte/Bit | 最高有效字节/位 |
| Block Read/Write | — | PMBus 块传输类型，第一个字节为数据长度 N，后续为 N 字节数据 |

### 错误检测与校验

| 术语 / 缩写 | 全称 | 说明 |
|-------------|------|------|
| PEC | Packet Error Check | 包错误校验，基于 CRC-8 的校验码，附加在每个事务末尾以确保数据完整性 |
| CRC-8 | Cyclic Redundancy Check 8-bit | 8 位循环冗余校验，多项式 C(x) = x^8 + x^2 + x + 1 (0x07) |

### 设备与存储相关

| 术语 / 缩写 | 全称 | 说明 |
|-------------|------|------|
| Host / Master | 主机 / 主设备 | 通过 PMBus 发送命令的控制器，通常是 BMC、MCU 或 FPGA |
| Slave / Device | 从设备 | 响应 PMBus 命令的电源模块 |
| NVM | Non-Volatile Memory | 非易失性存储器，掉电后数据不丢失 |
| EEPROM | Electrically Erasable Programmable ROM | 电可擦除可编程只读存储器，Omnion Power 模块用于存储配置参数 |
| Operating Memory | — | 运行时配置存储（RAM），掉电后丢失 |
| Default Store | — | 默认参数存储（NVM），通过 STORE_DEFAULT_ALL 写入，RESTORE_DEFAULT_ALL 恢复 |
| User Store | — | 用户自定义参数存储（NVM，如支持） |

### 状态与故障相关

| 术语 / 缩写 | 全称 | 说明 |
|-------------|------|------|
| FAULT | Fault | 故障，触发保护动作（关断、重启等） |
| WARNING | Warning | 警告，记录状态但不触发保护动作 |
| FAULT_RESPONSE | Fault Response | 故障响应配置，定义故障发生后的行为（关断/重启/延迟等） |
| FAULT_LIMIT | Fault Limit | 故障阈值，超过该值触发故障保护 |
| WARN_LIMIT | Warning Limit | 警告阈值，超过该值记录警告状态 |
| OVP / UVP | Over/Under Voltage Protection | 输出过压 / 欠压保护 |
| OCP | Over Current Protection | 输出过流保护 |
| OTP / UTP | Over/Under Temperature Protection | 过温 / 欠温保护 |
| PGOOD | Power Good | 电源正常指示信号，输出电压在规定范围内时有效 |
| CLEAR_FAULTS | — | 清除故障命令，清除锁存的故障状态并释放 SMBALERT# |

### 控制与配置相关

| 术语 / 缩写 | 全称 | 说明 |
|-------------|------|------|
| OPERATION | — | 操作命令，控制模块 ON/OFF 和裕量模式 |
| ON_OFF_CONFIG | — | ON/OFF 配置命令，定义硬件引脚行为和极性 |
| WRITE_PROTECT | — | 写保护命令，控制参数是否可修改 |
| PAGE | — | 页面选择命令，用于多路输出模块选择目标通道 |
| Margin High/Low | — | 裕量调节，将输出电压暂时偏移至高/低值用于测试 |
| Telemetry | — | 遥测数据，实时监测量（电压、电流、温度、功率等） |

## 1.4 Omnion Power 数字电源模块产品概览

### PMBus 协议兼容性

Omnion Power 数字电源模块的 PMBus 接口基于以下协议版本和标准实现：

| 特性 | 说明 |
|------|------|
| PMBus 规范版本 | Rev 1.2（Part I & Part II） |
| 总线速率 | 支持 100 kHz（标准模式）和 400 kHz（快速模式） |
| 时钟拉伸 | 支持，最大时钟低电平周期 35 ms |
| PEC | 支持 CRC-8 包错误校验，模块始终检查主机发送的 PEC 并在响应中包含 PEC |
| SMBALERT | 支持 SMBus 告警响应协议，可通过 SMBALERT# 信号主动通知主机 |
| 数据格式 | 仅支持 Linear 格式，不支持 Direct 格式 |
| 设备寻址 | 7-bit 地址，支持通过外部电阻编程配置多个地址 |
| 写保护 | 支持，通过 MFR 命令控制 |

### 通用功能概览

Omnion Power 数字电源模块的 PMBus 接口提供以下通用功能：

**遥测监测**

模块通过 PMBus 提供实时遥测数据，包括输入电压、输出电压、输出电流和模块温度。所有遥测命令使用 Read Word 传输类型，返回 16-bit Linear 格式数据。各参数的分辨率、精度和更新频率因产品而异，具体数值参见对应产品 Datasheet。

**故障保护**

模块支持完整的故障保护机制，涵盖输出过压（OVP）、输出欠压（UVP）、输出过流（OCP）、过温（OTP）和输入过压保护。故障阈值和故障响应行为均可通过 PMBus 命令配置。

**输出控制**

模块支持通过 PMBus OPERATION 命令实现软件 ON/OFF 控制，同时支持硬件 ON/OFF 引脚。两者可通过 ON_OFF_CONFIG 命令配置交互逻辑。

**裕量调节**

支持 Margin High / Margin Low 功能，用于系统生产测试阶段的电压裕量验证。

**状态报告**

模块提供 6 个 STATUS 寄存器（STATUS_BYTE、STATUS_WORD、STATUS_VOUT、STATUS_IOUT、STATUS_INPUT、STATUS_TEMPERATURE、STATUS_CML）用于故障和警告状态监测。

**非易失性存储**

模块支持将配置参数存储到内部 EEPROM（通过 STORE_DEFAULT_ALL 命令），上电时自动恢复。

**设备标识**

模块提供完整的制造商信息命令，包括 MFR_ID、MFR_MODEL、MFR_SERIAL、MFR_REVISION、MFR_DATE、MFR_LOCATION 等。

### 不支持的功能

为保持接口简洁和可靠性，Omnion Power 数字电源模块不实现以下 PMBus 功能：

| 不支持的功能 | 说明 |
|-------------|------|
| Direct 数据格式 | 仅使用 Linear 格式进行数值编码 |
| COEFFICIENTS 命令 | 不支持 Direct 格式参数配置 |
| SMBus ARP 协议 | 不支持地址解析协议 |
| GROUP 协议 | 不支持多设备同时寻址 |
| 多裕量模式 (Ignore Faults) | 仅支持 Act on Fault 模式 |
| Soft off with sequencing | 不支持序列化软关断 |

### 典型应用场景

Omnion Power 数字电源模块广泛应用于以下场景：

- 服务器与数据中心电源系统（PSU 通过 PMBus 连接 BMC）
- 通信设备电源管理
- 多路 POL 电源的集中监控与控制
- 工业自动化与测试测量设备

在这些场景中，PMBus 用于配置电源参数、读取实时遥测数据、监控故障状态以及远程控制电源的启停。PMBus 的带宽（100 kHz / 400 kHz）适合配置、监控和管理类应用，但不适合高速控制环路——电源的反馈控制在模块内部完成。

> **提示**: 关于 PMBus 协议的分层架构（I²C → SMBus → PMBus）和物理层细节，将在第 2 章中详细讲解。本章涉及的 Linear 数据格式将在第 5 章中详细讲解。PEC 校验将在第 6 章中详细讲解。SMBALERT 中断机制将在第 7 章中详细讲解。
