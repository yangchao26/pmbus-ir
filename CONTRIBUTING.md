# Contributing

PMBus IR is currently in an early design phase.

Contributions are most useful when they are grounded in real PMBus device behavior and help identify missing semantics in the common model.

When proposing schema changes:

1. provide a concrete device or interface use case;
2. explain what cannot be represented accurately today;
3. prefer general semantic concepts over vendor-specific naming;
4. avoid reproducing copyrighted normative specification text;
5. include or update an example and validation case where practical.
